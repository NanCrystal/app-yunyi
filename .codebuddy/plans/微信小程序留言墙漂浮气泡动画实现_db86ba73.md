## 产品概述

在微信小程序留言墙页面 (`pages/comments/comments`) 实现漂浮气泡式留言展示功能。用户可以查看所有历史留言以漂浮气泡形式持续动画上升，并通过悬浮按钮打开输入框创建新留言。整体风格为极简黑色主题，参考 PC 端 umi-blog 的 Comment 页面实现。

## 核心功能

- **接口调用**：通过 `GET /comments` 获取留言列表，`POST /comments` 创建新留言（复用已有后端 NestJS + Prisma 接口和项目 `request.ts` 封装）
- **悬浮消息按钮**：使用 `msg.svg` 图标，固定在页面右侧、距底部 30rpx，点击后从右向左滑出胶囊形状输入框（参考截图红色区域样式：圆角胶囊、深色背景、带发送按钮）
- **漂浮气泡动画**：所有留言以漂浮气泡形式渲染，持续执行 `floatUp` 关键帧动画（4 阶段：淡入 → 匀速上升 → 淡出消失），每条气泡具有 7 维随机差异化参数（水平位置、起止Y坐标、延迟、持续时间、字号、颜色）
- **大规模数据兼容**：
- 上万条留言时仅采样渲染约 50-80 个可见气泡，定期轮换内容，控制 WXML 节点数 < 1000
- 后端接口支持分页/限制返回数量，避免一次性传输全量数据
- 1000 人并发场景下接口增加缓存层与防抖策略

## 技术栈

- **前端框架**：微信小程序原生框架（WXML + WXSS + TypeScript）
- **动画方案**：纯 CSS `@keyframes` + `animation`（官方推荐的高性能动画方式），不使用 `setData` 轮询驱动
- **请求层**：复用项目现有 `services/request.ts`（`get<T>` / `post<T>` 封装，BASE_URL = `http://192.168.10.37:3000`）
- **后端接口**：已有 NestJS `CommentController`（GET/POST `/comments`）+ Prisma Service，无需修改

### 关键技术决策

#### 1. 微信小程序端 floatUp 动画实现方案

微信小程序 WXSS 完整支持 `@keyframes`、CSS 自定义属性（`var(--xxx)`）、`vw/vh` 单位、`animation` 全部子属性。因此可以直接移植 PC 端的 CSS 动画方案：

```css
/* 与PC端一致的4阶段关键帧 */
@keyframes floatUp {
  0%   { opacity: 0; transform: translateY(0); }
  5%   { opacity: 1; }
  90%  { opacity: 1; }
  100% { opacity: 0; transform: translateY(var(--end-y)); }
}

.bubble {
  position: absolute;
  top: var(--start-y);
  animation: floatUp linear infinite both;
}
```

**注意事项**：

- 小程序 `animation-fill-mode` 的 `both` 表现与 Web 一致（forwards + backwards 合并效果）
- Skyline 渲染模式下需确保 `rendererOptions.skyline.keyframeStyleIsolation: "legacy"` 使 keyframe 全局共享
- `position: fixed` 在 Skyline 下可能表现异常，建议用 `position: absolute` + 父容器 `position: relative; inset: 0` 替代

#### 2. 万级数据性能优化策略（核心难点）

| 问题 | 方案 | 说明 |
| --- | --- | --- |
| 10000+ 条留言无法全量渲染 | **采样池化** | 仅从全量数据中随机选取 `MAX_VISIBLE_BUBBLES`(默认60) 个渲染 |
| WXML 节点数 < 1000 限制 | **硬上限控制** | 气泡数 + UI 控制节点总数控制在 200 以内 |
| 动画期间切换内容闪烁 | **节点复用池** | 固定 60 个 DOM 节点，只替换其 style/data 内容，不增删节点 |
| 长时间观看内容重复 | **定时轮换器** | 每 15-20 秒重新从全量数据中采样一组新的 60 条，平滑过渡 |
| 首屏加载慢 | **分页加载** | 先拉取最新 200 条立即渲染，后台异步加载剩余数据补充池 |


**采样算法核心逻辑**：

```typescript
// 从全量列表中随机采样 N 条，构建气泡配置
function sampleAndBuild(list: CommentItem[], maxCount: number): BubbleConfig[] {
  // Fisher-Yates 洗牌后取前 N 条，保证随机性且无重复
  const shuffled = [...list].sort(() => Math.random() - 0.5);
  return shuffled.slice(0, maxCount).map(item => buildSingleConfig(item));
}
```

#### 3. 高并发(1000人同时使用)兼容方案

- **前端**：接口请求添加 `skipAuth: true`（留言为公开接口无需 token）；提交按钮防抖 500ms；失败自动重试 1 次
- **后端**（建议后续优化）：接口加 Redis 缓存（TTL 5s）；`findAll()` 加 `take(500)` 限制返回条数；创建接口加 rate-limit

### 实现细节要点

1. **buildConfigs 函数**：完全对齐 PC 端的 7 维随机参数（left: 5~95vw, startY: 50~130vh, endY: -30~-180vh, delay: 0~6s, duration: 8~12s, fontSize: 12~18px, color: hsla 随机色相）
2. **输入面板动画**：使用 `transform: translateX(100%)` → `translateX(0)` 的 CSS transition 实现右到左滑入，配合 `opacity` 渐变
3. **msg.svg 使用方式**：小程序中 SVG 作为 `<image>` 组件引用（src 指向本地路径），设置为圆形半透明背景按钮
4. **新增留言即时展示**：POST 成功后将新留言插入全量列表头部，并立即触发一次采样刷新，新留言有更高概率出现在当前可视气泡中

## 设计风格

采用极简深空黑色主题（Dark Space / Cyberpunk Neon UI 变体）。整个页面为纯黑背景（#000000），模拟深邃夜空的视觉感受。漂浮气泡使用虹彩色系（HSLA 随机色相、80%饱和度、72%亮度、85%透明度）形成霓虹灯般的发光文字效果，在黑色背景上缓缓上升飘散。输入面板采用毛玻璃拟态风格（Glassmorphism），半透明暗色背景配细边框，圆角胶囊造型，营造高端科技感。

### 页面块设计

#### 区块 1：导航区

页面顶部保留原生导航栏（已在 app.json 中配置为黑色背景 #000000 + 白色文字），标题可沿用 "STARVIEW ARCHIVE" 或改为 "留言墙"。导航栏与页面融为一体，无分割线。

#### 区块 2：漂浮气泡层 (bubbles-layer)

占据整个屏幕区域的绝对定位容器（inset: 0, overflow: hidden）。内部包含约 60 个以 `wx:for` 循环渲染的气泡节点，每个气泡绝对定位、执行 floatUp 无限循环动画。气泡文字颜色各异（虹彩随机色），大小不一（12-18px），从屏幕底部不同位置升起，向上方飘散淡出。用户视觉感受如同置身星空，周围漂浮着各色光点留言。

#### 区块 3：悬浮消息按钮 (msg-btn)

固定定位在屏幕右下角（right: 20rpx, bottom: 30rpx）。使用 msg.svg 图标（白色线条风格），包裹在直径 100rpx 的圆形半透明背景容器中（rgba(255,255,255,0.08)），带轻微白色边框。点击后有缩放反馈动效（scale: 0.9 → 1.0）。

#### 区块 4：输入面板 (input-panel)

点击消息按钮后，从屏幕右侧滑入的输入面板。覆盖在气泡层上方（z-index 更高）。样式参考截图红色区域：横向胶囊形状（border-radius: 50rpx），深色半透明背景（rgba(20,20,20,0.92)），内含 input 输入框（placeholder: "说点什么吧..."）+ 圆形发送按钮（播放三角形图标或箭头图标）。面板宽度占屏幕宽度的 85%。支持点击空白区域或关闭按钮收起面板。
